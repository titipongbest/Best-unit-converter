# BestSpace สำหรับ Android

เวอร์ชัน 1.0.x (เลขท้าย = ลำดับการ build)  •  by Northxbar

ตู้เข้ารหัสรูปแบบเดียวกับ BestSpace บนคอมทุกประการ – ตู้ที่สร้างบนคอมเปิดในมือถือได้ และตู้จากมือถือเปิดบนคอมได้
(ทดสอบไขว้กับโปรแกรมบนคอมทุกฟังก์ชัน: เนื้อไฟล์, โฟลเดอร์, เปลี่ยนรหัส, ไฟล์กุญแจ, .bsx, ไฟล์ขัดแย้งจากคลาวด์, ตัวนับรหัสผิด)

เวอร์ชันคอม (Windows/macOS/Linux) อยู่ที่ repo [Bestspace-python](https://github.com/titipongbest/Bestspace-python) – ไฟล์ .exe อยู่ใน Releases ของ repo นั้น

## ตู้อยู่ที่ไหน
- เริ่มต้น: `ที่เก็บข้อมูลหลัก/.bestspace` (`/storage/emulated/0/.bestspace`) – **ลบแอปแล้วตู้ยังอยู่** ติดตั้งใหม่แล้วเปิดตู้เดิมได้
- ไฟล์กุญแจ: `ที่เก็บข้อมูลหลัก/bestspace.key` (ข้างตู้ เหมือนบนคอมที่วางข้างโปรแกรม) – ลบแอปแล้วก็ยังอยู่
- เลือกตู้อื่น/สร้างที่อื่นได้ (เช่น SD card) • ย้ายตู้ไปคอม: คัดลอกโฟลเดอร์ `.bestspace` ทั้งโฟลเดอร์
- ต้องให้สิทธิ์ "เข้าถึงไฟล์ทั้งหมด" ตอนเปิดครั้งแรก (แอปไม่มีสิทธิ์อินเทอร์เน็ต ไฟล์ไม่ถูกส่งไปไหน)

## หน้าพราง (แอปโน้ต – โทนสว่างสดใส)
- เปิดแอปมาจะเจอแอปจดโน้ต/สิ่งที่ต้องทำธรรมดา (เพิ่ม ติ๊กเสร็จ ลบได้จริง – เก็บแยกจากตู้ ไม่เข้ารหัส อย่าจดของลับในนี้)
- **กดปุ่ม + ค้างไว้ 2 วินาที** → เข้าหน้ารหัสผ่านของตู้ (แตะสั้น ๆ = เพิ่มโน้ตตามปกติ, ลากนิ้วออกนอกปุ่ม = ยกเลิก)
- ล็อค / ออกจากแอป / กดย้อนกลับในหน้ารหัสผ่าน → กลับมาหน้าโน้ต
- **รหัสล็อคหน้าโน้ต** (ไม่บังคับ): ปุ่ม ⚙ มุมขวาบนของหน้าโน้ต → "ตั้งรหัสล็อคโน้ต" (ตัวเลข 4 หลัก)
  - ตั้งแล้ว: เปิดแอป / กลับเข้าแอป / ปิดจอแล้วเปิด / ล็อคตู้ → ต้องใส่รหัสก่อนเห็นโน้ต • ปุ่ม 🔒 บนหัวหน้าโน้ต = ล็อคทันที
  - เปลี่ยนรหัส / ปิดรหัส ได้ในหน้าตั้งค่า (ต้องใส่รหัสเดิมก่อน)
  - ไม่เก็บรหัสจริง เก็บแค่ salt + ค่า scrypt (N=2^14, r=8) • ผิดเกิน 5 ครั้งต้องรอนานขึ้นเรื่อยๆ (30 วิ → สูงสุด 15 นาที)
  - ลืมรหัส: "ลืมรหัส?" ในหน้าใส่รหัส → ลบโน้ตทั้งหมดแล้วเอารหัสออก (ตู้ไม่ถูกแตะ ยังใช้รหัสตู้เดิมเปิดได้)
  - รหัสนี้แยกจากรหัสตู้ – เป็นแค่ประตูหน้าแอปโน้ต ตู้ยังมีรหัสผ่าน/ไฟล์กุญแจของตัวเองเหมือนเดิม
  - **ลายนิ้วมือแทน PIN**: ตั้งค่า → "ปลดล็อคด้วยลายนิ้วมือ" (ต้องตั้ง PIN ก่อน – ใช้ตอนสแกนไม่ผ่าน)
  - ลายนิ้วมือใช้ได้กับหน้าโน้ตเท่านั้น – **ตู้จริงเปิดได้ด้วยรหัสผ่าน (+ไฟล์กุญแจ) เท่านั้น** ไม่มีกุญแจตู้ถูกเก็บไว้ที่ไหน

## ฟังก์ชัน (เท่าแอปคอม)
- สร้างตู้ / ปลดล็อค / ไฟล์กุญแจ / เปลี่ยนรหัสผ่าน (หมุน master key) / เพิ่มไฟล์กุญแจให้ตู้เดิม / สำรองไฟล์กุญแจ
- แกลเลอรี: โฟลเดอร์ (ภาพปก + จำนวนไฟล์), แท็บกรอง ทั้งหมด/รูป/วิดีโอ/เอกสาร/อื่นๆ, ค้นหาทั้งตู้, เรียง 4 แบบ, ปรับขนาดภาพย่อ
- กดค้างแล้วปล่อย = เลือกหลายไฟล์ → ย้าย / แชร์ .bsx / ส่งออก / ลบ / เปลี่ยนชื่อ / เปิดด้วยแอปอื่น / ข้อมูลไฟล์
- **กดค้างที่ไฟล์แล้วลาก = จัดลำดับไฟล์เอง** (ลากไปชิดขอบบน/ล่าง = เลื่อนรายการตาม) → การเรียงเปลี่ยนเป็น "กำหนดเอง"
  ลำดับเก็บในดัชนีที่เข้ารหัส (ซิงก์ข้ามเครื่องได้) • ไฟล์ที่เพิ่มใหม่อยู่บนสุดจนกว่าจะลากจัด • ย้ายไปโฟลเดอร์อื่น = เริ่มลำดับใหม่
  • ระหว่างค้นหาจัดลำดับไม่ได้ • อยู่ในแท็บกรอง (เช่น รูป) ลากจัดได้ ไฟล์ประเภทอื่นคงตำแหน่งเดิม
- **ภาพปกโฟลเดอร์เลือกเองได้**: เข้าไปในโฟลเดอร์ → ปุ่ม 🖼 (แถบบน) → แตะรูป/วิดีโอที่ต้องการ (หรือ "อัตโนมัติ" = ล่าสุด)
  หรือเลือกไฟล์ 1 ไฟล์ → ⋮ → "ตั้งเป็นภาพปกโฟลเดอร์นี้" • วิดีโอใช้ภาพปกของคลิป (ตั้งเฟรมได้ในหน้าเล่นวิดีโอ)
- ดูรูป: ปัดซ้ายขวา, สองนิ้วซูม, แตะสองครั้งซูม 250% – ซูมลึกถอดรูปละเอียดเต็มให้อัตโนมัติ
- เล่นวิดีโอ/เสียงในแอป: เลื่อนเวลา, ±10 วิ, ปิดเสียง, เต็มจอ, **ซูมวิดีโอ**, **ตั้งเฟรมปัจจุบันเป็นภาพปก**
- ไฟล์ข้อความ: สร้างใหม่ (+ → ข้อความใหม่), อ่าน/แก้ไขในแอป, บันทึกแบบเข้ารหัสโดยตรง, รองรับ UTF-8 และไทย TIS-620
- เพิ่มรูป/วิดีโอ/ไฟล์/ทั้งโฟลเดอร์ → **ลบต้นฉบับแบบเขียนทับ** + ลบออกจากแกลเลอรีของระบบ
- ส่งออก (ถอดรหัส) พร้อมตัวเลือกลบ GPS/ข้อมูลกล้องจากรูป • แชร์ .bsx ผ่านแอปอื่น (LINE/Drive/อีเมล) หรือบันทึกลงโฟลเดอร์
- นำเข้า .bsx (เข้ารหัสใหม่ด้วยคีย์ของตู้เอง – นำเข้าไฟล์เดิมซ้ำหลังลบได้ ไม่หายตอนซิงก์) • สำรองทั้งตู้ (ยังเข้ารหัส) • ล้างแคชและร่องรอย
- ใช้ตู้เดียวกันหลายเครื่องผ่านคลาวด์: เตือนเมื่อเปิดซ้อนกัน + รวมไฟล์ขัดแย้งให้อัตโนมัติ

## นำเข้า/ส่งออกไฟล์จำนวนมาก
- แถบความคืบหน้า: รวมทั้งงาน (ไฟล์ที่ / ทั้งหมด • ขนาด • % • เวลาที่เหลือ) + แถบของไฟล์ปัจจุบัน (เข้ารหัส → ตรวจสำเนา → ลบต้นฉบับ)
  ใช้กับ: เพิ่มรูป/ไฟล์/โฟลเดอร์, นำเข้า .bsx, ส่งออก, แชร์ .bsx, สำรองตู้
- **ปุ่มยกเลิก**: หยุดที่ไฟล์ปัจจุบัน – ไฟล์ที่เสร็จแล้วคงไว้ (นำเข้า: ลงตู้แล้ว / ส่งออก: ตรวจอ่านกลับแล้ว), ไฟล์ที่ค้างครึ่งทางถูกลบทิ้ง,
  ต้นฉบับของไฟล์ที่ยังไม่ได้ทำไม่ถูกแตะ • สำรองตู้ที่ยกเลิก = ลบโฟลเดอร์ .part ทิ้ง
- นำเข้าหลายพันไฟล์: ลงดัชนีทีละชุด (สูงสุด 100 ไฟล์ หรือทุก ~3 วินาที) แทนการบันทึกดัชนีทุกไฟล์ → ไม่ช้าลงเรื่อยๆ เมื่อตู้ใหญ่
  ต้นฉบับถูกลบหลังชุดนั้นลงดัชนี + ตรวจสำเนาผ่านแล้วเท่านั้น
- ระหว่างทำงาน: จอไม่ดับเอง • ปุ่มย้อนกลับไม่ปิดแอป • ไม่ล็อคเองเพราะ "ไม่มีการใช้งาน"
  • สลับไปแอปอื่น/กดปิดจอ = ปิดทับจอทันที (แสดงแค่ความคืบหน้า ไม่มีชื่อไฟล์) งานทำต่อด้วยบริการเบื้องหน้า แล้วล็อคเมื่อเสร็จ
- ถูกขัดจังหวะ (แบตหมด / แอปถูกปิด / เครื่องค้าง) **ไฟล์ไม่เสียหาย**:
  - นำเข้า: ลบต้นฉบับหลังไฟล์ลงดัชนีบนดิสก์ + ตรวจสำเนาผ่านแล้วเท่านั้น → ดับตรงไหนก็มีอย่างน้อยหนึ่งชุดครบเสมอ
    ไฟล์ที่เข้ารหัสค้างครึ่งทาง (ยังไม่ลงดัชนี) ถูกเก็บกวาดตอนปลดล็อคครั้งหน้า (ต้นฉบับยังอยู่ นำเข้าใหม่ได้)
  - ส่งออก / แชร์ .bsx: เขียนลงชื่อชั่วคราว `.bestspace-xxxx.part` (ซ่อน ไม่บอกชื่อจริง แกลเลอรีไม่สแกน) → อ่านกลับเทียบทุกไบต์ → ค่อยตั้งชื่อจริง
    ไม่มีไฟล์ชื่อจริงที่เขียนไม่ครบ และไฟล์ชั่วคราวที่ค้างถูกเขียนทับ+ลบตอนเปิดแอปครั้งหน้า
  - สำรองตู้: เขียนลงโฟลเดอร์ `<ชื่อ>.part` → ตรวจทุกไฟล์ → ค่อยเปลี่ยนชื่อ (ไม่มีโฟลเดอร์สำรองที่ดูครบแต่จริงๆ ขาด)
  - รายการงานที่ค้างเก็บในพื้นที่ส่วนตัวของแอป (มีแค่ path ชั่วคราว/รหัสไฟล์ ไม่มีชื่อไฟล์จริง)
- การแจ้งเตือนระหว่างทำงานไม่มีชื่อไฟล์และซ่อนบนหน้าจอล็อค (Android 13+ ถ้าไม่ได้อนุญาตการแจ้งเตือน งานก็ยังทำต่อได้ตามปกติ)

## ล็อค = ปิดแอปแล้วเปิดใหม่
- ทุกครั้งที่ล็อค (กดล็อค / ไม่มีการใช้งาน / ออกจากแอป / ปิดจอ) แอปจะล้างของที่ต้องล้าง แล้ว **ปิดโปรเซสของตัวเอง**
  → หน่วยความจำทั้งหมด (รวมเศษข้อความ/ภาพที่ระบบหรือไลบรารีปล่อยไว้ ซึ่งแอปล้างเองไม่ได้) คืนระบบ
- ล็อคตอนแอปอยู่บนจอ: เปิดใหม่ทันทีที่หน้าโน้ต (กระพริบแวบเดียว) • ล็อคตอนอยู่เบื้องหลัง: ปิดเฉยๆ กลับเข้าแอปเมื่อไรก็เริ่มใหม่
- มีงานนำเข้า/ส่งออกค้าง: รอให้งานเสร็จก่อนแล้วค่อยล็อค + ปิด

## ความปลอดภัย
- AES-256-GCM ทุกไฟล์ (คีย์แยกต่อไฟล์) • รหัสผ่าน: scrypt • ดู/เล่น/แก้ไข: ถอดรหัสในหน่วยความจำเท่านั้น
- ห้ามแคปหน้าจอ/อัดหน้าจอ • ภาพในหน้า "แอปล่าสุด" เป็นสีดำ (Android 13+ ไม่เก็บภาพไว้เลย)
- Android 12+: ซ่อนหน้าต่างลอยของแอปอื่นขณะเปิดแอป (กันแอปอื่นวางหน้าต่างใสดักการแตะ/รหัสผ่าน)
- ล็อคทันทีเมื่อออกจากแอป/ปิดจอ • ล็อคเองเมื่อไม่ใช้ 3 นาที (ระหว่างเล่นวิดีโอไม่นับ) • มีงานค้าง = ปิดทับจอแล้วล็อคเมื่องานเสร็จ
- ใส่รหัสผิด 3 ครั้งเริ่มต้องรอ (30 วิ เพิ่มเท่าตัว สูงสุด 1 ชม.) จำไว้ 2 ที่ • แจ้งเตือนเมื่อมีคนพยายามเปิดตู้
- คีย์บอร์ดไม่จำสิ่งที่พิมพ์ในแอป (รหัส/ชื่อไฟล์/ข้อความ) • ล้างคลิปบอร์ดตอนล็อค • ห้ามระบบสำรองข้อมูลแอปขึ้นคลาวด์
- เปิดด้วยแอปอื่น: ถอดรหัสชั่วคราวในพื้นที่ส่วนตัวของแอป ชื่อไฟล์สุ่ม เขียนทับ+ลบตอนล็อค • ไม่เปิดไฟล์ .apk/โปรแกรม

ข้อจำกัด: หน่วยความจำแฟลชอาจยังเก็บข้อมูลเก่าหลังเขียนทับ (Android เข้ารหัสทั้งเครื่องอยู่แล้ว) •
รูปที่สำรองขึ้น Google Photos ต้องลบในแอปนั้นด้วย • ระหว่างเปิดหน้าต่างเลือกไฟล์/แอปอื่น ตู้ล็อคเมื่อไม่ได้ใช้ 3 นาที

### กุญแจเซ็นแอป (ทำก่อนใช้งานจริง)
ไม่ตั้ง = เซ็นด้วยกุญแจทดสอบที่สุ่มใหม่ทุกครั้ง → อัปเดตทับไม่ได้ ต้องถอนแอปก่อน
(ตู้อยู่ในที่เก็บข้อมูลหลักแล้ว ถอนแอปตู้ไม่หาย แต่ต้องอนุญาตสิทธิ์ใหม่)
สร้างเองบนคอม (PowerShell):

```powershell
cd $env:USERPROFILE\Documents
$kt = (Get-ChildItem "$env:USERPROFILE\.jdks\*\bin\keytool.exe" | Select-Object -First 1).FullName
& $kt -genkeypair -keystore bestspace-release.jks -storetype PKCS12 -alias bestspace -keyalg RSA -keysize 4096 -validity 36500 -dname "CN=BestSpace"
[Convert]::ToBase64String([IO.File]::ReadAllBytes("bestspace-release.jks")) | Set-Content KEYSTORE_BASE64.txt
```
แล้วใน GitHub: Settings → Secrets and variables → Actions → เพิ่ม `KEYSTORE_BASE64` (เนื้อหาไฟล์ txt) และ `KEYSTORE_PASSWORD`
